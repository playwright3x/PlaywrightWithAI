# PlaywrightWithAI

A collection of Playwright + TypeScript learning and automation projects.

## Projects

- **JavaScripts_TypeScript** — JavaScript/TypeScript fundamentals exercises.
- **LearningPlayWrightWithParmod** — Playwright course work following Parmod's training.
- **LearningPlaywright3x** — Playwright 3x learning project.
- **LearningPlaywrightFundamentals3x** — Playwright fundamentals: locators, iframes, shadow DOM, file upload/download, POM, fixtures, and more (chapter-organized under `tests/`).
- **Shashank_Pandit_Learning** — Personal learning notes and exercises.
- **Shashank_learning** — Playwright automation practice: assignments and login test scenarios.

Each project folder is self-contained with its own `package.json` and `playwright.config.ts`. To run a project's tests:

```bash
cd <project-folder>
npm install
npx playwright test
```
